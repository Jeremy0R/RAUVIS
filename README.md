# RAUVIS: Realidad Aumentada y Ciberseguridad

RAUVIS es una aplicación móvil educativa orientada a mitigar la brecha digital y fortalecer la cultura de la ciberseguridad en adultos mayores[cite: 13]. Mediante el uso de Realidad Aumentada (RA), el sistema transforma conceptos abstractos de seguridad informática en experiencias visuales, tangibles y libres de riesgo. 

## 🎯 Características Principales

* **Aprendizaje Tangible (AR):** Utiliza la cámara del dispositivo para escanear tarjetas físicas (marcadores) y desplegar simulaciones interactivas mediante el SDK de Vuforia.
* **Asistente Virtual (Botty):** Un guía interactivo que acompaña al usuario en todo momento, brindando instrucciones claras, retroalimentación inmediata y apoyo bimodal (texto y voz).
* **Diseño Accesible (UI/UX):** Interfaz minimalista optimizada para adultos mayores, con tipografías de gran tamaño, paletas de colores pastel de alto contraste y zonas de interacción táctil amplias.
* **Arquitectura 100% Local:** El progreso de las lecciones y las preferencias del usuario se almacenan internamente en el dispositivo mediante `PlayerPrefs`, garantizando un funcionamiento fluido sin conexión a internet y la protección absoluta de la privacidad de los datos.

## 🛡️ Módulos de Aprendizaje

El diseño instruccional del proyecto establece una navegación guiada a través de seis escenarios de riesgo cotidiano:

1. **La llave de tu casa:** Creación de contraseñas seguras mezclando letras, números y símbolos.
2. **El cartero falso:** Identificación de remitentes sospechosos y prevención de ataques de *phishing*.
3. **El paquete sorpresa:** Uso de un escáner antivirus simulado para prevenir la descarga de archivos adjuntos maliciosos.
4. **Un favor sospechoso:** Toma de decisiones críticas ante ataques de ingeniería social basados en el sentido de urgencia.
5. **El puente engañoso:** Uso de una herramienta virtual (Lupa) para revelar y verificar enlaces fraudulentos ocultos en botones.
6. **Las cadenas de mentiras:** Identificación y eliminación de cadenas de correos engañosas para detener la desinformación.

## 💻 Tecnologías Utilizadas

* **Motor Gráfico:** Unity 3D.
* **Realidad Aumentada:** Vuforia Engine SDK.
* **Lenguaje de Programación:** C#.
* **Plataforma de Despliegue:** Android nativo.

## 🚀 Instalación y Uso

1. Descarga el archivo `.apk` desde la sección de *Releases* de este repositorio o accediendo al siguiente link:
https://drive.google.com/drive/folders/1ijuZBo_4_OHlDwqUvmLnKVFU-IAFbxa_?usp=sharing
2. Instala la aplicación en tu dispositivo Android.
3. Otorga los permisos de acceso a la cámara solicitados por el sistema operativo.
4. Imprime el set de tarjetas físicas (marcadores) ubicadas en el directorio correspondiente del repositorio que se encuentran en el link proporcionado.
5. Inicia la aplicación en un entorno con iluminación adecuada y sigue las instrucciones de bienvenida del asistente virtual.
