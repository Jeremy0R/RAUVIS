# RAUVIS: Realidad Aumentada y Ciberseguridad

<img width="2000" height="2000" alt="Acerca_De" src="https://github.com/user-attachments/assets/cbc1e82d-3849-4f45-9a06-01e52497ab5c" />


RAUVIS es una aplicación móvil educativa orientada a mitigar la brecha digital y fortalecer la cultura de la ciberseguridad en adultos mayores[cite: 13]. Mediante el uso de Realidad Aumentada (RA), el sistema transforma conceptos abstractos de seguridad informática en experiencias visuales, tangibles y libres de riesgo[cite: 13]. 

## 🎯 Características Principales

* **Aprendizaje Tangible (AR):** Utiliza la cámara del dispositivo para escanear tarjetas físicas (marcadores) y desplegar simulaciones interactivas mediante el SDK de Vuforia[cite: 13].
* **Asistente Virtual (Botty):** Un guía interactivo que acompaña al usuario en todo momento, brindando instrucciones claras, retroalimentación inmediata y apoyo bimodal (texto y voz)[cite: 13].
* **Diseño Accesible (UI/UX):** Interfaz minimalista optimizada para adultos mayores, con tipografías de gran tamaño, paletas de colores pastel de alto contraste y zonas de interacción táctil amplias[cite: 13].
* **Arquitectura 100% Local:** El progreso de las lecciones y las preferencias del usuario se almacenan internamente en el dispositivo mediante `PlayerPrefs`, garantizando un funcionamiento fluido sin conexión a internet y la protección absoluta de la privacidad de los datos[cite: 13].

## 🛡️ Módulos de Aprendizaje

El diseño instruccional del proyecto establece una navegación guiada a través de seis escenarios de riesgo cotidiano[cite: 13]:

1. **La llave de tu casa:** Creación de contraseñas seguras mezclando letras, números y símbolos[cite: 12].
2. **El cartero falso:** Identificación de remitentes sospechosos y prevención de ataques de *phishing*[cite: 12].
3. **El paquete sorpresa:** Uso de un escáner antivirus simulado para prevenir la descarga de archivos adjuntos maliciosos[cite: 12].
4. **Un favor sospechoso:** Toma de decisiones críticas ante ataques de ingeniería social basados en el sentido de urgencia[cite: 12].
5. **El puente engañoso:** Uso de una herramienta virtual (Lupa) para revelar y verificar enlaces fraudulentos ocultos en botones[cite: 12].
6. **Las cadenas de mentiras:** Identificación y eliminación de cadenas de correos engañosas para detener la desinformación[cite: 12].

## 💻 Tecnologías Utilizadas

* **Motor Gráfico:** Unity 3D[cite: 13].
* **Realidad Aumentada:** Vuforia Engine SDK[cite: 13].
* **Lenguaje de Programación:** C#[cite: 13].
* **Plataforma de Despliegue:** Android nativo[cite: 13].

## 🚀 Instalación y Uso

1. Descarga el archivo `.apk` desde la sección de *Releases* de este repositorio.
2. Instala la aplicación en tu dispositivo Android.
3. Otorga los permisos de acceso a la cámara solicitados por el sistema operativo[cite: 13].
4. Imprime el set de tarjetas físicas (marcadores) ubicadas en el directorio correspondiente del repositorio.
5. Inicia la aplicación en un entorno con iluminación adecuada y sigue las instrucciones de bienvenida del asistente virtual[cite: 13].
